Tags:
----
    ->Tags are pre-define words which are enclosed with both opening and closing angular brackets.
    Ex:
        <h1>,<meta>,<title>,<p>,<figure>,</figure></p></title></h1>

Types of tags:
    i. paired tags
        h${heading-$}*6 ---- shortcut for heading tags from h1 to h6
        h1 size -- font size 32 pixels
        h2 size  --font size 24
        h3 size --font size 18.72
        h5 size --font size 16
        h4 size --font size 13.26
        h6 size --font size 10.72
    ii.formatted tags
        <b> </b> -- bold text
        <em> </em> -- emphasized text
        <strong> </strong> -- strong text
        <strike> </strike> -- to strike text
        <sub> </sub> -- subscript text
        <sup> </sup> -- superscript text
        <i> </i> -- italic text
        <u> </u> -- underline text
        <s> </s> -- strikethrough text
        <mark> </mark> -- highlighted text
        <center> </center> -- center aligned text
        <marque> </marquee> -- scrolling texts
